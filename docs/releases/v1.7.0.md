Bilibili Cookie 讀取器換上冰藍底色與青綠線路圖。匯入前可以看到 `cookies.txt` 對應的四個欄位，匯入後即可在同一區檢查欄位值與到期資訊。

- 在左欄選擇帳號，按「選擇 Cookie 檔案」或直接拖入檔案。也可貼上路徑，按 Enter 讀取。
- 欄位預設遮罩，可切換明文或逐項複製。捲動結果時，登入驗證與匯出工具固定在底部。

請下載符合平台的 ZIP，解壓後執行 `BilibiliCookieReader.exe`（Windows）或 `BilibiliCookieReader`（macOS、Linux）。各套件已包含 .NET 執行階段。可使用隨附的 `SHA256SUMS.txt` 核對下載檔。
